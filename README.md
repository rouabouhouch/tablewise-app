# Tablewise

[Open Tablewise on GitHub Pages](https://rouabouhouch.github.io/tablewise-app/)

Open a CSV to explore its columns, chart patterns and check data quality. Use **Predict** to train and evaluate a model on your own records. The sample bike trips are synthetic.

CSV processing and model training run in your browser. This repository contains the static files served by GitHub Pages from the root of `main`.
